# Sales Data Analysis

Projeto de análise de dados de vendas desenvolvido em Python.

## Objetivo

Analisar os dados de vendas de uma empresa, identificando padrões de faturamento por vendedor, produto e período.

## Tecnologias

- Python
- NumPy
- Pandas
- Matplotlib
- Excel

## Projeto

O projeto utiliza uma base de controle de vendas contendo:

- Nome do vendedor
- Período da venda
- Produto
- Valor unitário
- Quantidade
- Valor total

## Análises

Serão analisados:

- Faturamento total
- Ticket médio
- Maior e menor venda
- Faturamento por vendedor
- Faturamento por produto
- Faturamento por período
- Quantidade de vendas por vendedor
- Visualizações dos resultados
